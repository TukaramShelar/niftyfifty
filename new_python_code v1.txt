2. Python Script Implementation (main.py)
The Python script fetches data using requests, formats the values, and appends them to Google Sheets using gspread and google-auth.

Complete main.py Code

import os
import json
import requests
import datetime
import gspread
from google.oauth2.service_account import Credentials

def get_market_data():
    """Fetch daily market metrics (FII/DII, PCR, GIFT Nifty)."""
    today_str = datetime.date.today().strftime('%Y-%m-%d')
    
    # Placeholder structure for fetched market metrics
    # Under live market hours, real API/Scraper endpoints populate these fields
    fii_buy = 0.0
    fii_sell = 0.0
    fii_net = 0.0
    dii_buy = 0.0
    dii_sell = 0.0
    dii_net = 0.0
    pcr = 0.0
    gift_nifty = 0.0
    gift_nifty_change = "0.0%"
    
    row = [
        today_str,
        fii_buy,
        fii_sell,
        fii_net,
        dii_buy,
        dii_sell,
        dii_net,
        pcr,
        gift_nifty,
        gift_nifty_change
    ]
    return row

def get_gspread_client():
    """Authenticate with Google Sheets via Environment Variable or local JSON file."""
    scopes = [
        "https://www.googleapis.com/auth/spreadsheets",
        "https://www.googleapis.com/auth/drive"
    ]
    
    # Check if running inside GitHub Actions environment
    if "GCP_SERVICE_ACCOUNT" in os.environ:
        service_account_info = json.loads(os.environ["GCP_SERVICE_ACCOUNT"])
        creds = Credentials.from_service_account_info(service_account_info, scopes=scopes)
    else:
        # Local development fallback
        creds = Credentials.from_service_account_file("service_account.json", scopes=scopes)
        
    return gspread.authorize(creds)

def run():
    print("Fetching Daily Market Data...")
    row_data = get_market_data()
    print("Collected Row Data:", row_data)
    
    client = get_gspread_client()
    sheet_name = os.environ.get("SPREADSHEET_NAME", "NiftyDailyData")
    
    spreadsheet = client.open(sheet_name)
    worksheet = spreadsheet.sheet1
    
    worksheet.append_row(row_data)
    print("Successfully logged data into Google Sheet!")

if __name__ == "__main__":
    run()



3. GitHub Actions Workflow (daily_run.yml)
The workflow defines the environment, triggers, dependencies, and execution sequence for running the python script on GitHub's cloud runners.

Directory Path Rule
The file MUST be located at exact path: .github/workflows/daily_run.yml

Complete daily_run.yml Code

name: Daily Market Data Fetcher

on:
  schedule:
    # 8:55 AM IST corresponds to 3:25 AM UTC (Monday to Friday)
    - cron: '25 3 * * 1-5'
  workflow_dispatch: # Allows manual triggering from GitHub UI

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout Repository
      uses: actions/checkout@v3

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.10'

    - name: Install Dependencies
      run: |
        python -m pip install --upgrade pip
        pip install requests gspread google-auth

    - name: Execute Data Fetch Script
      env:
        GCP_SERVICE_ACCOUNT: ${{ secrets.GCP_SERVICE_ACCOUNT }}
        SPREADSHEET_NAME: "NiftyDailyData"
      run: python main.py
